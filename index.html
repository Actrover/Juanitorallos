2 Mathematical Expression

What is a Mathematical Expression?

A mathematical expression is a combination of numbers, variables, and operation symbols that represents a value.

Examples from Notes

1. The difference of a number and 5
Let x be the number → x − 5
2. The product of 10 and a number
→ 10x
3. The quotient of a number and 50
→ x / 50
4. One-fifth of a number
→ x / 5 or (1/5)x
5. Three-fourths of 500
→ (3/4) × 500 = 375
6. The sum of two numbers less 11
Let x = first number, y = second number
→ (x + y) − 11
7. Double the quantity of sales less taxes
→ 2x − y
8. The difference of gross sales less taxes
→ x − y
9. A number subtracted from 8
→ 8 − x

Sample Problems (from notes)

Problem: The sum of two numbers is 45 and their difference is 11. Find the numbers.

Let x = first number
Let y = x + 11
x + (x + 11) = 45
2x + 11 = 45
2x = 34
x = 17
y = 17 + 11 = 28
Problem: The average of two quizzes is 85. The first quiz is 10 points higher than the second. What are the values of the two quizzes?

Let x = second quiz
First quiz = x + 10
(x + (x + 10)) / 2 = 85
(2x + 10) / 2 = 85
2x + 10 = 170
2x = 160
x = 80
First quiz = 90

3 Sets

Definition of a Set

A set is a well-defined collection of distinct objects. The objects in the set are called elements.

Example:
A = {1, 2, 3, 4}
B = {a, b, c, d}

Well-Defined Set

A set is well-defined if we can clearly determine whether an object belongs to the set or not.

Well-defined: The set of counting numbers less than 10
Not well-defined: The set of beautiful flowers (subjective)

4 Different Types of Sets

1. Empty Set / Null Set

A set with no elements. Denoted by ∅ or { }.

The set of counting numbers less than 0 → ∅

2. Finite Set

A set with a limited number of elements.

A = {1, 2, 3, 4, 5} → finite
Set of days in a week → finite

3. Infinite Set

A set with unlimited number of elements.

Set of counting numbers: {1, 2, 3, 4, …}
Set of whole numbers: {0, 1, 2, 3, …}

4. Equal Sets

Two sets are equal if they have exactly the same elements.

A = {1, 2, 3, 4}
B = {4, 3, 2, 1}
A = B (same elements)

5. Equivalent Sets

Two sets are equivalent if they have the same number of elements (same cardinality).

A = {1, 2, 3, 4}
B = {a, b, c, d}
A and B are equivalent (both have 4 elements)

6. Universal Set

The set of all elements under consideration. Denoted by U.

U = {1, 2, 3, 4, 5, 6, 7}
A = {1, 2, 3, 4}

7. Set Complement

The complement of set A (written A′ or Ac) is the set of all elements in the universal set that are not in A.

U = {1, 2, 3, 4, 5, 6, 7}
A = {1, 2, 3, 4}
A′ = {5, 6, 7}

8. Proper Subset

Set A is a proper subset of set B (A ⊂ B) if all elements of A are in B, and A ≠ B.

A = {1, 2, 3, 4, 5}
B = {1, 2, 3, 4, 5, 6, 7}
A ⊂ B

9. Improper Subset

Every set is an improper subset of itself. Also, the empty set is a subset of every set.

A = {1, 2, 3, 4, 5}
A ⊆ A (improper subset)

5 Set Operations

1. Intersection (A ∩ B)

The set of elements that are common to both A and B.

A = {1, 2, 3, 4}
B = {2, 3, 5, 6, 7}
A ∩ B = {2, 3}

2. Union (A ∪ B)

The set of elements that belong to either A or B or both.

A = {1, 2, 3, 4}
B = {3, 4, 5}
A ∪ B = {1, 2, 3, 4, 5}

3. Disjoint Sets

Two sets are disjoint if they have no elements in common (A ∩ B = ∅).

A = {1, 2, 3}
B = {4, 5, 6}
A ∩ B = ∅ → Disjoint sets

6 Venn Diagram

What is a Venn Diagram?

A Venn diagram uses circles inside a rectangle (universal set) to show relationships between sets.

A ∪ B (Union)
A ∩ B (Intersection)

Examples from Notes

Given:
A = {1, 2, 3, 4, 5}
B = {1, 2, 3, 4, 5, 6, 7}
A ⊂ B (A is a proper subset of B)
Intersection Example:
A = {1, 2, 3, 4}
B = {2, 3, 5, 6, 7}
A ∩ B = {2, 3}
Union Example:
A = {1, 2, 3, 4}
B = {3, 4, 5}
A ∪ B = {1, 2, 3, 4, 5}
Remember:
• Shaded region in A ∩ B = only the overlapping part
• Shaded region in A ∪ B = everything inside both circles

7 Reasoning (Inductive and Deductive)

1. Inductive Reasoning

Inductive reasoning starts from specific examples or observations and then forms a general conclusion or pattern.

The conclusion is probable (likely true) but not 100% certain.

How it works:

  1. Observe specific cases or examples
  2. Look for a pattern
  3. Make a general conclusion based on the pattern
Example 1:
2 + 1 = 3 (odd)
4 + 1 = 5 (odd)
6 + 1 = 7 (odd)
8 + 1 = 9 (odd)

Conclusion: The sum of an even number and 1 is always an odd number.
Example 2:
3² = 9
5² = 25
7² = 49
9² = 81

Conclusion: The square of an odd number is always odd.
Example 3:
1 = 1²
1 + 3 = 4 = 2²
1 + 3 + 5 = 9 = 3²
1 + 3 + 5 + 7 = 16 = 4²

Conclusion: The sum of the first n odd numbers is equal to n².
Example 4:
5, 10, 15, 20, 25, …

Conclusion: These are multiples of 5. The next number is 30.
Note: Inductive reasoning is useful for discovering patterns, but the conclusion can still be wrong if a counter-example is found later.

2. Deductive Reasoning

Deductive reasoning starts from general statements (rules, definitions, or theorems) and reaches a specific conclusion.

If the premises are true, the conclusion must be true.

How it works:

  1. Start with a general rule or known fact
  2. Apply it to a specific case
  3. Reach a certain conclusion
Example 1:
Premise 1: All even numbers are divisible by 2.
Premise 2: 14 is an even number.
Conclusion: Therefore, 14 is divisible by 2.
Example 2:
Premise: The sum of the angles in any triangle is 180°.
In triangle ABC, ∠A = 50° and ∠B = 60°.
Conclusion: ∠C = 180° − 50° − 60° = 70°.
Example 3:
If a number is a multiple of 6, then it is a multiple of both 2 and 3.
18 is a multiple of 6.
Conclusion: 18 is a multiple of 2 and of 3.
Example 4:
All squares have four equal sides.
Figure ABCD is a square.
Conclusion: Figure ABCD has four equal sides.

Comparison: Inductive vs Deductive

Aspect Inductive Deductive
Direction Specific → General General → Specific
Based on Patterns / examples Rules / definitions / theorems
Certainty Conclusion is probable Conclusion is certain (if premises are true)
Used for Discovering patterns, making conjectures Proving statements, solving problems
